= Fronius
Solar PV inverter, smart meter and Gen24 hybrid inverter integration by Fronius.

== Overview

This bundle provides integration with Fronius photovoltaic (PV) inverter systems, Fronius Smart Meter devices, and the Fronius Symo Gen24 hybrid inverter with battery storage. Fronius is an Austrian manufacturer of solar inverters and energy management solutions. The integration enables monitoring of solar production via the PV inverter, energy measurement via the Smart Meter, and full battery inverter control via the Gen24 components, all using Modbus TCP communication.
The bundle supports five main components:

PV Inverter - Monitors and can limit solar generation from Fronius Symo and compatible inverters
Smart Meter - Reads three-phase grid power measurement from Fronius Smart Meter
Gen24 Battery Inverter - Controls the Fronius Symo Gen24 hybrid inverter via SunSpec Modbus
Gen24 Battery - Reads battery state (SoC, voltage, current, capacity) from the Gen24 inverter
Gen24 DC Charger - Exposes individual PV string power/voltage/current from the Gen24 inverter

== Supported Devices

Fronius PV Inverter:

- Model: Fronius Symo (and compatible models)
- Type: Grid-connected solar inverter
- Communication: Modbus TCP/RTU via SunSpec register map
- Power Rating: 3-27 kW typical
- Features: Real-time power monitoring, active power limitation
- Firmware: Current versions supporting SunSpec protocol

Fronius Smart Meter:

- Models: 63A-3, TS 65A-3
- Type: Three-phase AC electricity meter
- Communication: Modbus TCP/RTU via SunSpec register map
- Rated Current: 63-65 A per phase
- Features: Real-time power and energy measurement
- Configuration: Can use SunSpec Model Type float or integer
- Typical Use: Grid power measurement, export/import monitoring

Fronius Symo Gen24 Hybrid Inverter:

- Model: Fronius Symo Gen24 (Plus)
- Type: Hybrid grid-connected inverter with battery management
- Communication: Modbus TCP via integrated Modbus server (int+SF register format)
- Features: Battery charge/discharge control, PV string monitoring, SunSpec Model 123 power limiting
- Firmware: Current versions tested

Fronius Gen24 Battery:

- Compatible batteries: BYD HVS, BYD HVM, Fronius Reserva, Fronius Reserva Pro, LG Battery Flex
- Communication: Data read directly from the Gen24 inverter via Modbus
- Features: State of charge, voltage, current, charge/discharge limits, module count
- Configuration: Modbus server must be set to int+SF format

Fronius Gen24 DC Charger:

- Type: Virtual component exposing individual PV string data from the Gen24 inverter
- Communication: Data read directly from the Gen24 inverter (no separate Modbus connection)
- Features: Real-time DC power, voltage and current per PV string
- Strings: Supports PV string ONE and TWO

== Important Configuration Notes
=== Smart Meter SunSpec Configuration
The Fronius Smart Meter must be configured to use SunSpec Model Type float (not integer). This is a critical setting:

Access Fronius Smart Meter web interface
Navigate to Settings → Communication
Set SunSpec Model Type to "float" (not "integer")
Save and restart meter if necessary

Without this configuration, the OpenEMS integration will not read correct values.
=== Gen24 Modbus Server Configuration
The Fronius Gen24 inverter must be configured to use int+SF register format in its Modbus server:

Access the Fronius Gen24 web interface
Navigate to Communication → Modbus
Enable Modbus TCP server
Set register format to int+SF (not float)

=== Gen24 Component Independence
The three Gen24 components (Battery Inverter, Battery, DC Charger) each connect directly to Modbus and perform their own independent SunSpec discovery against the same physical Fronius Gen24 device — there is no OSGi reference between them.

Make sure modbus_id and modbusUnitId are configured identically (same physical device, same Unit-ID) across all Gen24 components you use, since they all talk to the same inverter independently.
=== Read-Only Mode vs Managed Mode
PV Inverter has two operating modes:

Read-Only Mode (readOnly: true): Only monitors solar generation, no commands sent to inverter
Managed Mode (readOnly: false): Allows OpenEMS controllers to limit active power output

Start with read-only mode for testing, then enable managed mode if power limitation is needed.
