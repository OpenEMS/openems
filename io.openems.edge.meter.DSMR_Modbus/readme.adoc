= io.openems.edge.meter.DSMR_Modbus

https://github.com/OpenEMS/openems/tree/develop/io.openems.edge.meter.DSMR_Modbus[Source Code icon:github[]]

This is an implementation of a DSMR compliant meter through its 'P1' port - converted with a generic modbus over TCP/IP converter. 

DSMR = Dutch Smart Meter Requirements, of which all meters in the Netherlands are compliant to. This component instance is specifically aimed at meters complaint to v5.0, supporting fast updating.
For more info DSMR see: 
https://www.netbeheernederland.nl/sites/default/files/2024-02/dsmr_v4.2.3_final_main.pdf
https://github.com/energietransitie/dsmr-info/tree/main

A generic P1 to modbus over TCP IP converter is available from several vendors, most of them are ESP32 based. The only requirement is that the following Modbus table is used:

For this to work, you install the generic Bridge Modbus/TCP and link it to this component. 
The complete chain is thus:

- Smart meter issued by Liander/Stedin/Enexis or other DSO
- P1 to Modbus over TCP/IP converter

In openEMS:
- Bridge Modbus/TCP
- DSMR_Modbus meter component.
