= Stabl ESS

Driver for the Stabl battery storage system, communicating over Modbus TCP.

Supports up to 3 strings of battery modules. Per-module power distribution can optionally be delegated to an external solver via HTTP — when disabled, internal fallback ranks are used.

Implemented Natures:

- ManagedSymmetricEss
- ManagedSinglePhaseEss
- AsymmetricEss
- SymmetricEss
