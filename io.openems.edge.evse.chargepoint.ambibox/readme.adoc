= Ambibox ambiCHARGE Home

Bidirectional EV charger with Modbus/TCP interface.

== Overview

This bundle implements the Ambibox ambiCHARGE Home charger as an OpenEMS
https://github.com/OpenEMS/openems/tree/develop/io.openems.edge.evse.api[EVSE Charge-Point]
for charge management. Bidirectional discharge (Vehicle-to-Home) management is not
standardized in OpenEMS yet and is out of scope of this bundle.

The implementation is based on the protocol description "User Interface (Modbus
TCP) - v1" and the EVCC Ambibox charger implementation
(https://github.com/evcc-io/evcc/blob/master/charger/ambibox.go[evcc ambibox.go]).

== Modbus/TCP protocol

All values are 32 bit (2 Modbus registers, big endian, most significant word
first). Each physical connector occupies its own register block; one OpenEMS
component is configured per connector.

.Holding Registers (EV Charger)

|===

== Target Power AC sign convention

Following the EVCC implementation, a negative target power value commands the
charger to charge the electric vehicle; positive values would discharge it
(which is not used by this bundle). The OpenEMS channel `SetTargetPower` is
positive for charging; the sign is inverted when writing the Modbus register.
