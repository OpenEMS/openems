= Victron Battery Inverter

Implementation of Victron Battery Inverter.


== Compatibility 
- Victron Multiplus 2GX ESS

== Battery sources

`Victron.Battery` reads the selected battery service from the Victron GX Modbus/TCP server. The default source is the CAN-bus BMS (Unit-ID 225). To use the virtual battery produced by `dbus-battery-aggregator`, configure:

* Battery source: `DBUS_AGGREGATOR`
* Modbus Unit-ID: `99` (the aggregator's default DeviceInstance)
* Nominal battery voltage: the nominal voltage of the battery bank, in V (decimal values are supported; use the rated nominal voltage, not the charge voltage)
* Minimum discharge voltage: the BMS-approved minimum voltage of the battery bank, in V (decimals are rounded up to the next whole volt for the integer channel)

The aggregator combines its serial batteries into one battery service; configure one `Victron.Battery` component for that aggregate rather than one component per physical pack. The minimum discharge voltage is required because the aggregate service does not provide it. Confirm the DeviceInstance and Modbus register values on the GX before enabling battery control.

Battery capacity is reported by the Victron Modbus service in Ah and converted to OpenEMS Wh using the configured nominal battery voltage.

== Victron Meter Grid

`Victron.Meter.Grid` reads a grid meter connected to a Victron GX device via its Modbus/TCP server (service `com.victronenergy.grid`, Unit-ID depending on the instance of the meter).

[cols="1,2,2",options="header"]
|===
|Register |Victron |OpenEMS Channel

|2600-2602 |`/Ac/L1-L3/Power`, int16, W |`ActivePowerL1-L3`
|2609 |`/Serial`, string[7] |`SerialNumber`
|2616, 2618, 2620 |`/Ac/L1-L3/Voltage`, uint16, 0.1 V |`VoltageL1-L3`
|2617, 2619, 2621 |`/Ac/L1-L3/Current`, int16, 0.1 A |`CurrentL1-L3`
|2622-2626 |`/Ac/L1-L3/Energy/Forward` ("Energy from net"), uint32, 0.01 kWh |`ActiveProductionEnergyL1-L3`
|2628-2632 |`/Ac/L1-L3/Energy/Reverse` ("Energy to net"), uint32, 0.01 kWh |`ActiveConsumptionEnergyL1-L3`
|2644 |`/Ac/Frequency`, uint16, 0.01 Hz |`Frequency`
|===

For a grid meter, OpenEMS defines energy bought from the grid as Active Production Energy and energy sold to the grid as Active Consumption Energy. The total energies are calculated as the sum of the phases.

The frequency register 2644 is not part of register list 2.80; it was added in revision 49 of the register list. It is read in a separate task, so that an error when reading this register does not affect the other values.

Protocol documentation (Victron "Modbus TCP register list"):

* `doc/CCGX-Modbus-TCP-register-list-3.81.xlsx` (current)
* `doc/CCGX-Modbus-TCP-register-list-2.80.xlsx`
