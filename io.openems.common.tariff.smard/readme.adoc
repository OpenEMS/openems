= EPEX SPOT / SMARD

This implementation uses the https://www.smard.de/[SMARD - Strom- und Gasmarktdaten für Deutschland] platform to receive day-ahead electricity prices for European bidding zones.
The platform supports the following bidding zones: Germany, Austria, Belgium, Netherlands and Czechia.
The SMARD spot price component (```Tariff.SpotTariff.SMARD```) is available in Backend and Edge versions of OpenEMS.

== Authentication

The SMARD API does not require an authentication token.
