= Time-Of-Use Tariff API

Provides abstract access for getting prices from every "Time-Of-Use" tariff providers like:

- aWATTar by tado°
- Corrently by STROMDAO
- ENTSO-E spot prices
- EWS Schönau
- Groupe E
- Stadtwerk Haßfurt
- LUOX Energy by Lumenaza
- rabot.charge
- Swisspower
- Tibber
- ...
