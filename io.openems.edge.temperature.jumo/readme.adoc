= Jumo HydroTrans S20

Integrates the Jumo HydroTrans S20 transmitter for measuring humidity, temperature, and CO2 via Modbus.

== Overview

Provides integration with the Jumo HydroTrans S20 environmental sensor via Modbus RTU/TCP.
It reads various climate parameters such as relative humidity, temperature, CO2 concentration, dew point, and related physical values.
Typically used in building automation, environmental monitoring, and HVAC control systems.

== Supported Devices

.Jumo HydroTrans S20
* **Type**: Environmental sensor / transmitter (Humidity, Temperature, CO2)
* **Communication**: Modbus RTU/TCP
* **Typical Use**: Indoor climate and environmental monitoring
* **Documentation**: https://www.jumo.net[Jumo Official Website icon:external-link[]]
