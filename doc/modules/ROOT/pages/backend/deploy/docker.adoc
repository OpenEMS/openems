This chapter explains how OpenEMS Backend can be deployed using our official https://hub.docker.com/r/openems/backend[Docker image].

The involved components (Edge.Manager, Backend.Edge.App) and the available deployment options are described in xref:backend/architecture.adoc[Backend Architecture]. The Docker images follow this architecture: the *openems/backend* image contains the central Backend with the Edge Manager, while the separate *openems/backend-edge* image runs the Backend Edge Application that the OpenEMS Edge devices connect to.

== Prepare system

=== Connect to the server

[source,bash]
----
ssh admin@ubuntu
----

=== Check docker installation

[source,bash]
----
admin@ubuntu:~$ docker --version
Docker version 27.3.1, build ce12230
----

__if not already installed, follow <<Setup docker>>__

=== Setup docker

To setup docker follow the instructions from https://docs.docker.com/engine/install/[docs.docker.com].

== Start Container 

=== Create a Docker compose

Paste content into a `docker-compose.yml` in a directory of your choice:

[source,yaml]
----
services:
  openems_backend:
    image: openems/backend:latest
    container_name: openems_backend
    hostname: openems_backend
    restart: unless-stopped
    volumes:
      - openems-backend-conf:/var/opt/openems/config:rw
      - openems-backend-data:/var/opt/openems/data:rw
    ports:
      - 8079:8079 # Apache-Felix

  openems_backend_edge:
    image: openems/backend-edge:latest
    container_name: openems_backend_edge
    hostname: openems-backend-edge
    restart: unless-stopped
    volumes:
      - openems-backend-edge-conf:/var/opt/openems/config:rw
      - openems-backend-edge-data:/var/opt/openems/data:rw
    ports:
      - 8078:8078 # Apache-Felix
      - 8081:8081 # Edge-Websocket

volumes:
  openems-backend-conf:
  openems-backend-data:
  openems-backend-edge-conf:
  openems-backend-edge-data:
----

=== Run compose file

To start the previously created `docker-compose.yml` `cd` into the directory of it and run the command:

[source,bash]
----
docker compose up -d
----

=== Check logs

To check if the container is up and running, check `docker ps`:

[source,bash]
----
admin@ubuntu:~$ docker ps

[source,bash]
----
docker logs openems_backend
----

=== Connect the Backend Edge Application

The Backend Edge Application in the *openems/backend-edge* container needs to connect to the Edge Manager in the *openems/backend* container.

. Open the http://localhost:8078/system/console/configMgr[Apache Felix Web Console Configuration icon:external-link[]] of the *openems/backend-edge* container.
+
Login with username *admin* and password *admin*.

. Configure the _**Backend Edge Application**_ service: set *Uri* to the address of the *openems/backend* container, e.g. `ws://openems_backend:8083`.
+
The port must match the *Port* of the _**Edge Manager**_ service in the *openems/backend* container (default `8083`). Click btn:[Save].

== OpenEMS Backend UI

If you want to add the OpenEMS Backend UI to your setup, you can do so by adjusting your `docker-compose.yml` file to look like this:

[source,yaml]
----
services:
  openems_backend:
    image: openems/backend:latest
    container_name: openems_backend
    hostname: openems_backend
    restart: unless-stopped
    volumes:
      - openems-backend-conf:/var/opt/openems/config:rw
      - openems-backend-data:/var/opt/openems/data:rw
    ports:
      - 8079:8079 # Apache-Felix
      - 8082:8082 # UI-Websocket

  openems_backend_edge:
    image: openems/backend-edge:latest
    container_name: openems_backend_edge
    hostname: openems-backend-edge
    restart: unless-stopped
    volumes:
      - openems-backend-edge-conf:/var/opt/openems/config:rw
      - openems-backend-edge-data:/var/opt/openems/data:rw
    ports:
      - 8078:8078 # Apache-Felix
      - 8081:8081 # Edge-Websocket

  openems-ui:
    image: openems/ui-backend:latest
    container_name: openems_ui
    hostname: openems_ui
    restart: unless-stopped
    volumes:
      - openems-ui-conf:/etc/nginx:rw
      - openems-ui-log:/var/log/nginx:rw
    environment:
      - WEBSOCKET_HOST=openems_backend
      - WEBSOCKET_PORT=8082
    ports:
      - 80:80
      - 443:443

volumes:
  openems-backend-conf:
  openems-backend-data:
  openems-backend-edge-conf:
  openems-backend-edge-data:
  openems-ui-conf:
  openems-ui-log:
----

summary of the changes:

1. Open a Port for UI Websocket (8082) on the `openems-backend` service
2. Added a new service `openems-ui` to the docker-compose file
3. Added the volumes `openems-ui-conf` and `openems-ui-log`

== Add InfluxDB Container

=== Update docker-compose

to add InfluxDB to your setup, you can do so by adjusting your `docker-compose.yml`, by adding the following lines:

[source,yaml]
----
  …
  openems-influxdb:
    image: influxdb:2.9-alpine
    container_name: openems-influxdb
    hostname: openems-influxdb
    restart: unless-stopped
    volumes:
      - openems-influxdb2-data:/var/lib/influxdb2:rw
    ports:
      - 8086:8086

volumes:
  …
  openems-influxdb2-data:
----

=== Setup InfluxDB

==== Setup InfluxDB

[source,bash]
----
docker exec openems_influxdb influx setup \
  --username openems \
  --password WKeuIhl0deIJjrjoY62M \
  --org openems.io \
  --bucket openems \
  --force
----

[source,bash]
----
docker exec openems_influxdb influx auth list
----

NOTE: Note down Token

==== Open Backend Apache-Felix.

Open the http://localhost:8079/system/console/configMgr[Apache Felix Web Console Configuration icon:external-link[]] of the *openems/backend* container and login with username *admin* and password *admin*.

1. Remove Timedata.Dummy
2. Add Timedata.InfluxDB

[%noheader,cols="1,1",width="50%"]
|===
| Query Language | INFLUX_QL
| URL | http://openems-influxdb:8086
| Org | openems.io
| ApiKey | InfluxDB-Token
| Bucket | openems
|===

NOTE: Values not specified can be left at their default values
Timedata.InfluxDB 	

for further information see OpenEMS docs
