[#sec-terms]
== Terms

[cols="2*",options="header"]
|===
| Term
| Meaning

| Edge
| The OpenEMS software on the energy management device on site.
| Backend
| Central server through which systems can be monitored remotely.
| UI
| The web interface (online monitoring).
| Component
| A building block of the system in OpenEMS, e.g. a meter, the storage or a control function. Each component has an ID such as `+ess0+` (storage) or `+meter0+` (grid meter).
| Channel
| A single measured value or control value, e.g. `+_sum/EssSoc+` (state of charge of the storage).
| Controller
| A control function that decides anew every second, e.g. grid-optimized charge.
| Meta
| The general system settings: location, currency, grid connection limits.
|===
