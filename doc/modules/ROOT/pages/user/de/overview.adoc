[#sec-begriffe]
== Begriffe

[cols="2*",options="header"]
|===
| Begriff
| Bedeutung

| Edge
| Die OpenEMS-Software auf dem Energiemanagement-Gerät vor Ort.
| Backend
| Zentraler Server, über den Anlagen aus der Ferne überwacht werden können.
| UI
| Die Weboberfläche (Online-Monitoring).
| Komponente
| Ein Baustein der Anlage in OpenEMS, z. B. ein Zähler, der Speicher oder eine Regelfunktion. Jede Komponente hat eine ID wie `+ess0+` (Speicher) oder `+meter0+` (Netzzähler).
| Kanal
| Ein einzelner Messwert oder Steuerwert, z. B. `+_sum/EssSoc+` (Ladezustand des Speichers).
| Controller
| Eine Regelfunktion, die jede Sekunde neu entscheidet, z. B. die netzdienliche Beladung.
| Meta
| Die allgemeinen Systemeinstellungen: Standort, Währung, Netzanschluss-Grenzen.
|===
