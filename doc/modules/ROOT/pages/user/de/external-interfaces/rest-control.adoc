Über die REST-Schnittstelle können Fremdsysteme wie eine Hausautomation (Home Assistant, ioBroker, Node-RED …) oder eigene Skripte **Werte aus OpenEMS lesen und die Anlage steuern**. Es genügen einfache HTTP-Aufrufe.

[#sec-einrichten]
== Einrichten

Es gibt zwei Varianten:

[cols="2*",options="header"]
|===
| Funktion
| erlaubt

| Controller.Api.Rest.ReadOnly
| nur lesen
| Controller.Api.Rest.ReadWrite
| lesen und steuern
|===

* **Port:** standardmäßig 8084.
* **Anmeldung:** mit dem Passwort eines OpenEMS-Benutzers. Der Benutzername ist beliebig, üblich ist `+x+`. Was erlaubt ist, hängt von der Rolle des Benutzers ab.
* **Api-Timeout:** standardmäßig 60 Sekunden (Erklärung unten).

Tipp: Wer nur aktuelle Werte lesen will, sollte die ReadOnly-Variante verwenden. Die Adresse `+/jsonrpc+` funktioniert dort nicht, auch nicht für reine Abfragen wie Verläufe; dafür ist die ReadWrite-Variante und mindestens die Rolle Eigentümer nötig (siehe xref:user/de/data/export.adoc[Daten exportieren]).

[#sec-werte-lesen]
== Werte lesen

[source]
----
http://x:PASSWORT@IP-DER-ANLAGE:8084/rest/channel/_sum/EssSoc
----

liefert z. B. den Ladezustand des Speichers mit Einheit:

[source]
----
{"type":"INTEGER","accessMode":"RO","text":"","unit":"%","value":57}
----

Mit Platzhaltern lassen sich mehrere Werte auf einmal abfragen, z. B. die Leistung aller Zähler: `+/rest/channel/meter.*/ActivePower+`.

Häufig genutzte Werte:

[cols="2*",options="header"]
|===
| Adresse
| Bedeutung

| `+_sum/GridActivePower+`
| Netzleistung (positiv = Bezug, negativ = Einspeisung)
| `+_sum/ProductionActivePower+`
| Solarleistung
| `+_sum/ConsumptionActivePower+`
| Verbrauch
| `+_sum/EssSoc+`
| Ladezustand des Speichers
| `+_sum/EssDischargePower+`
| Speicherleistung (positiv = Entladen)
|===

[#sec-steuern-zwei-grundverschiedene-wege]
== Steuern: zwei grundverschiedene Wege

[cols="3*",options="header"]
|===
| 
| Steuerwert setzen
| Einstellung ändern

| Beispiel
| „Speicher jetzt mit 2 kW laden“, „Relais 1 ein“
| „Preissteuerung ausschalten“, „Risikobereitschaft auf Hoch“
| Dauer
| **vorübergehend**
| **dauerhaft**, auch nach Neustart
| Rolle
| Eigentümer (über diesen Weg)
| Eigentümer
| Geeignet für
| häufige, laufende Steuerung
| seltene Änderungen
|===

[#sec-steuerwert-setzen]
=== Steuerwert setzen

[source]
----
POST http://x:PASSWORT@IP-DER-ANLAGE:8084/rest/channel/ess0/SetActivePowerEquals
Inhalt: {"value": -2000}
----

(Beim Speicher bedeutet ein negativer Wert Laden, ein positiver Entladen.)

**Wichtig – der Api-Timeout:** Ein gesetzter Steuerwert gilt nur, solange er regelmäßig erneuert wird. Kommt innerhalb des Api-Timeouts (Standard 60 Sekunden) kein neuer Wert, verwirft OpenEMS ihn, und die Anlage kehrt zu ihrem normalen Verhalten zurück.

* Das ist eine **Schutzfunktion**: Fällt die Hausautomation aus, bleibt der Speicher nicht dauerhaft auf einem alten Befehl stehen.
* **Wer dauerhaft steuern will, muss den Wert regelmäßig senden**, deutlich häufiger als der Timeout, z. B. alle 10 bis 30 Sekunden.
* Ein leerer Wert hebt den Befehl sofort auf.

Nur Werte, die zum Steuern gedacht sind, können gesetzt werden. Bei reinen Messwerten kommt die Meldung „is not a Write Channel“. Andere Funktionen und Grenzen gelten weiter, z. B. die Notstromreserve oder die Netzgrenzen. Ein Befehl wird deshalb nicht immer vollständig umgesetzt.

[#sec-einstellung-aendern]
=== Einstellung ändern

Einstellungen werden über die Adresse `+/jsonrpc+` geändert (siehe xref:user/de/external-interfaces/json-rpc.adoc[JSON-RPC]):

[source]
----
POST http://x:PASSWORT@IP-DER-ANLAGE:8084/jsonrpc
Inhalt:
{
  "method": "updateComponentConfig",
  "params": {
    "componentId": "ctrlEssTimeOfUseTariff0",
    "properties": [ { "name": "mode", "value": "OFF" } ]
  }
}
----

Die Änderung wird gespeichert und gilt sofort. **Einstellungen nicht im Minutentakt ändern.** Jede Änderung wird auf den Speicher des Geräts geschrieben, und bei SD-Karten oder eMMC führt häufiges Schreiben auf Dauer zu Verschleiß. Für laufende Steuerung sind Steuerwerte gedacht.

[#sec-haeufige-probleme]
== Häufige Probleme

* **Befehl wirkt nur eine Minute:** Das ist der Api-Timeout. Der Wert muss regelmäßig erneut gesendet werden.
* **„is not a Write Channel“:** Der Wert ist nur lesbar. Oft ist eigentlich eine Einstellung gemeint.
* **Zugriff verweigert:** Die Rolle des Benutzers reicht nicht aus.
* **„Read-Only mode“:** Es ist nur die ReadOnly-Variante eingerichtet.
* **Falsche Adresse:** Einstellungen gehen an `+/jsonrpc+`. Die Dokumentation im Quellcode nennt fälschlich `+/rest/jsonrpc+`.
