This page complements it with the parts of an OpenEMS Component and uses a Controller as a template: **Balancing** (self-consumption optimization, bundle `+io.openems.edge.controller.ess.balancing+`), which is small, complete and has a test. For charge points, `+CLAUDE.md+` names the bundles `+io.openems.edge.evse.chargepoint.keba+` and `+…mennekes+` as templates; for Modbus devices see xref:development/implementing/modbus-device-drivers.adoc[Modbus device drivers].

== Files of a bundle

[source]
----
io.openems.edge.controller.ess.balancing/

  readme.adoc                     description for the documentation
  src/io/openems/edge/controller/ess/balancing/

    ControllerEssBalancing.java   interface with its own Channels

  test/io/openems/edge/controller/ess/balancing/

In `+bnd.bnd+`, `+-buildpath+` lists all required OpenEMS bundles in addition to `+${buildpath}+`, here `+io.openems.common+`, `+io.openems.edge.common+`, `+io.openems.edge.controller.api+`, `+io.openems.edge.ess.api+`, `+io.openems.edge.meter.api+`. `+${buildpath}+` and `+${testpath}+` are defined in `+cnf/build.bnd+` (Gson, Guava, OSGi annotations, logging, JUnit).

[#sec-config-java]
== Config.java

The configuration is an annotation with OSGi Metatype. The form in the Apache Felix Web Console and the fields shown by the UI are created from it.

[source]
----
@ObjectClassDefinition(name = "Controller Ess Balancing",
        description = "Optimizes the self-consumption by keeping the grid meter on zero.")
@interface Config {
    @AttributeDefinition(name = "Component-ID", description = "Unique ID of this Component")
    String id() default "ctrlBalancing0";

    @AttributeDefinition(name = "Alias", description = "Human-readable name ...")
    String alias() default "";

    @AttributeDefinition(name = "Is enabled?", description = "Is this Component enabled?")
    boolean enabled() default true;

    @AttributeDefinition(name = "Ess-ID", description = "ID of Ess device.")
    String ess_id();

    @AttributeDefinition(name = "Grid-Meter-ID", description = "ID of the Grid-Meter.")
    String meter_id();

    @AttributeDefinition(name = "Target Grid Setpoint", description = "...")
    int targetGridSetpoint() default 0;

    String webconsole_configurationFactory_nameHint() default "Controller Ess Balancing [{id}]";
}
----

* Every component has `+id+`, `+alias+` and `+enabled+`.
* An underscore in the method name becomes a dot in the property name: `+ess_id()+` reads the property `+ess.id+`.
* `+webconsole_configurationFactory_nameHint+` determines the display name in the Apache Felix Web Console.

[#sec-interface-with-its-own-channels]
== Interface with its own Channels

[source]
----
public interface ControllerEssBalancing extends Controller, OpenemsComponent {
    public enum ChannelId implements io.openems.edge.common.channel.ChannelId {
        DEBUG_SET_GRID_ACTIVE_POWER(Doc.of(OpenemsType.INTEGER)
                .accessMode(AccessMode.READ_ONLY)),
        SET_GRID_ACTIVE_POWER(Doc.of(OpenemsType.INTEGER)
                .accessMode(AccessMode.WRITE_ONLY)
                .onChannelSetNextWriteMirrorToDebugChannel(DEBUG_SET_GRID_ACTIVE_POWER));
        ...
    }
}
----

Here there is a write-channel via which another Controller or an interface can specify the grid setpoint. `+onChannelSetNextWriteMirrorToDebugChannel+` mirrors the written value to a readable Channel so that it is visible in the history and UI.

[#sec-implementation]
== Implementation

[source]
----
@Designate(ocd = Config.class, factory = true)
@Component(
        name = "Controller.Symmetric.Balancing",    // Factory-PID, never change
        immediate = true,
        configurationPolicy = ConfigurationPolicy.REQUIRE)
@GenerateTargetsFromReferences({ "ess", "meter" })
public class ControllerEssBalancingImpl extends AbstractOpenemsComponent
        implements Controller, OpenemsComponent, ModbusSlave, ControllerEssBalancing {

    @Reference(policy = STATIC, policyOption = GREEDY, cardinality = MANDATORY,
            target = "(&(id=${config.ess_id})(enabled=true))")
    private ManagedSymmetricEss ess;

    @Reference(policy = STATIC, policyOption = GREEDY, cardinality = MANDATORY,
            target = "(&(id=${config.meter_id})(enabled=true))")
    private ElectricityMeter meter;

    private Config config;

    public ControllerEssBalancingImpl() {
        super(OpenemsComponent.ChannelId.values(),
              Controller.ChannelId.values(),
              ControllerEssBalancing.ChannelId.values());
    }

    @Activate
    private void activate(ComponentContext context, Config config) {
        super.activate(context, config.id(), config.alias(), config.enabled());
        this.config = config;
    }

    @Override
    @Deactivate
    protected void deactivate() {
        super.deactivate();
    }

    @Override
    public void run() throws OpenemsNamedException {
        if (!this.ess.isOnGridOrUndefined(m -> this.logWarn(this.log, m))) {
            return;
        }
        int target = this.getSetGridActivePowerNextWriteValue()
                .orElse(this.config.targetGridSetpoint());
        var power = this.meter.getActivePower().getOrError()
                + this.ess.getActivePower().getOrError() - target;
        this.ess.setActivePowerEqualsWithFilter(power);
        this.ess.setReactivePowerEqualsWithoutFilter(0);
    }
}
----

(shortened; in the original, the calculation is in a static method `+calculateRequiredPower+`, which can be tested individually)

[#sec-what-the-parts-do]
=== What the parts do

* **`+configurationPolicy = REQUIRE+`**: the component is only created if a configuration exists.
* **Constructor**: pass all `+ChannelId+` enums of the implemented Natures. If one is missing, its Channels do not exist and access fails at runtime.
* **`+implements+`**: list all Natures, including parent interfaces (see xref:development/fundamentals/components-and-channels.adoc[Components and Channels in code]).
* **`+getOrError()+`**: throws an exception if the value is missing (e.g. meter not reachable). The Scheduler catches it and sets `+RunFailed+`. If you want to handle missing values differently, use `+get()+` (can be `+null+`) or `+orElse(…)+`.
* **Setpoints** to ESS go through ESS Power; details under xref:development/fundamentals/cycle-and-ess-power.adoc[Cycle].

[#sec-references-to-other-components]
== References to other components

A Controller receives meters and ESS via OSGi `+@Reference+`. Which Instance is meant is specified in the configuration (`+ess_id+`). For OSGi to inject the correct Instance, the reference needs a **target filter** with this ID.

**New way (139 classes):** `+@GenerateTargetsFromReferences+` from `+io.openems.core.referencetarget+`. `+target+` contains a placeholder `+${config.ess_id}+`; a configuration plugin replaces it with the value of the property when loading the configuration. The annotation contains the names of the references (field name or, for setter methods such as `+setModbus+`, the reference name).

**Old way (still in a few classes):** an additional property `+ess_target+` in the Config and the call `+OpenemsComponent.updateReferenceFilter(cm, servicePid(), "ess", config.ess_id())+` in `+activate()+`. This writes the filter to the configuration and triggers a reactivation.

Options of the reference:

[cols="2*",options="header"]
|===
| Option
| Effect

| `+cardinality = MANDATORY+`
| Without a matching component, the Controller is not activated.
| `+cardinality = OPTIONAL+` / `+MULTIPLE+`
| none or one / any number of components; with `+policy = DYNAMIC+`, the field must be `+volatile+` or a thread-safe list.
| `+policy = STATIC+`
| If the reference changes, the component is reactivated. Simple and safe.
| `+policy = DYNAMIC+`
| Reference is replaced at runtime, without reactivation.
| `+policyOption = GREEDY+`
| immediately binds a better matching component as soon as it appears.
|===

The filter `+(enabled=true)+` ensures that disabled components are not bound.

[#sec-other-common-building-blocks]
== Other common building blocks

* **`+debugLog()+`**: returns a short string that “Controller Debug Log” outputs every second (e.g. `pass:c["L:" + getActivePower().asString()]`).
* **`+ModbusSlave+`**: makes Channels readable or writable via the Modbus/TCP API (`+getModbusSlaveTable()+`).
* **`+EventHandler+`**: for work outside `+run()+` in a Cycle Event; the topics are in the `+@Component+` property `+EventConstants.EVENT_TOPIC+`.
* **Clock**: `+componentManager.getClock()+` instead of `+Instant.now()+`; the clock can then be controlled in tests.
* **Logging**: `+this.logInfo(log, …)+`, `+logWarn+`, `+logError+` from `+AbstractOpenemsComponent+` prefix the Component-ID.
* **`+readme.adoc+`**: is included in this documentation.

[#sec-checklist-for-a-new-bundle]
== Checklist for a new bundle

. Create the directory `+io.openems.edge.<area>.<name>+` with `+bnd.bnd+`, `+src+`, `+test+`, `+readme.adoc+` (the easiest way is to copy a similar bundle).
. Choose a unique Factory-PID in `+@Component(name = …)+`; scheme e.g. `+Controller.Ess.Xyz+`, `+Meter.Manufacturer.Type+`.
. Write a test with `+ComponentTest+`/`+ControllerTest+` (xref:development/testing/component-tests.adoc[Component tests]).
. Run `+./gradlew :<bundle>:test+` and `+:<bundle>:checkstyleMain+`.
. Enter the bundle in `+io.openems.edge.application/EdgeApp.bndrun+` under `+-runrequires+` so that it is part of the Edge JAR.
. Follow the xref:development/coding-guidelines.adoc[Coding Guidelines] and run `+./tools/prepare-commit.sh+`.
